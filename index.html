    A tiny, open-source tool that reads your PUBG logs and Windows crash records, then tells you the likely cause of your crashes — and what to try, cheapest first. It changes nothing on your PC and uploads nothing.
    

    
    Why this exists
    That “Out of video memory” error is usually lying. On an 8 GB+ card at 1080p you aren’t actually out of VRAM — the real cause is normally an unstable RAM/XMP profile, a shaky overclock, a starved pagefile, a bad driver, or a tired PSU. This tool finds which.
    

    
    Run it in 3 steps (Windows)
    
    
      
      
    1. Download this repo (green Code ▾ → Download ZIP) and unzip it anywhere.
      2. 
      
    2. Double-click Run-Diagnostic.bat  — or right-click diagnose.ps1 → Run with PowerShell.
      3. 
      
    3. Your browser opens this page with your results: a verdict, the evidence, and an ordered fix list.
      4. 
    
    
    
    Prefer the command line? powershell -ExecutionPolicy Bypass -File diagnose.ps1
    

    
    

    
    What it checks
    
    
    
      
    PUBG logs
    GPU-crash, “out of video memory”, render-thread hangs
    
      
    Event Viewer
    Kernel-Power 41, WHEA hardware faults, driver TDRs
    
      
    Memory
    XMP/EXPO state & actual vs rated speed
    
      
    System
    Pagefile, GPU driver & date, VRAM, disk health
    
    
    

    
    This is a community troubleshooting aid, not official PUBG/KRAFTON software. It is read-only and open source — inspect diagnose.ps1 before running if you like. No warranty; hardware changes are at your own risk.
